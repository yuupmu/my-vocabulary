# 나의 단어장

React를 사용해서 단어카드를 추가하고 삭제할 수 있게 만들었습니다

## React의 3가지 핵심 요소

### 1. 컴포넌트
화면에 보여질 ui 블록을 묶어둔 것으로, 재사용이 가능합니다.
이번 과제에서는 단어 카드를 WordCard, 그리고 출력을 WordList 로 묶어두었기 때문에
카드가 여러개 필요해도 호출만 하면 간편하고 가독성 좋게 불러올 수 있습니다.

### 2. Props

props는 상위에서 하위 컴포넌트로 데이터를 전달할 때 쓰이는 객체입니다
WordList 컴포넌트가 WordCard 컴포넌트를 호출할 때 정보랑 상태를 전달합니다. 

### 3. State
State는 컴포넌트에서 변화하는 데이터를 관리합니다. 값이 변경되면 화면에 리렌더링을 유발합니다.
사용자가 단어 추가, 삭제 등을 하면 state 값이 업데이트 되어 react가 화면을 다시 그려냅니다.
